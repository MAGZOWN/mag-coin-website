# MAG COIN Code of Conduct

## Our Commitment

MAG COIN is committed to building a respectful, transparent, and professional community.

We welcome constructive discussion, responsible feedback, and collaboration conducted in good faith.

All participants are expected to contribute to an environment that is welcoming, respectful, and free from harassment.

---

## Expected Behaviour

Community members are encouraged to:

- Be respectful and courteous.
- Communicate professionally.
- Provide constructive feedback.
- Respect differing opinions.
- Help improve the project through honest discussion.
- Report security concerns responsibly.
- Follow applicable laws and regulations.

---

## Unacceptable Behaviour

The following behaviour is not acceptable:

- Harassment or personal attacks.
- Hate speech or discrimination.
- Threats or intimidation.
- Spam or repetitive promotional content.
- Distribution of malicious software.
- Phishing attempts.
- Impersonation of MAG COIN representatives.
- Publication of false or misleading information intended to harm the project.
- Disclosure of confidential security information.
- Illegal activity of any kind.

---

## Security

Please do not report security vulnerabilities publicly.

Follow the responsible disclosure process described in:

SECURITY.md

---

## Enforcement

The MAG COIN project reserves the right to remove, edit, or reject contributions, comments, discussions, or interactions that violate this Code of Conduct.

Repeated or serious violations may result in permanent removal from project communication channels.

---

## Scope

This Code of Conduct applies to:

- GitHub repository
- Official website
- Official Telegram
- Official X account
- Official Instagram
- Public discussions representing MAG COIN

## Before Requesting Support

Please verify:

- You are using the official MAG COIN website.
- You have verified the official contract address.
- You are interacting only with official project links.
- Your wallet software is up to date.
- You never share your seed phrase or private keys.

## Reporting Website Problems

If you discover a technical issue with the official website, please include:

- Description of the issue
- Browser and device information
- Steps to reproduce
- Screenshots if available

Send reports to:

info@coinmagbase.com
